# Fuzzy-sistem

Projeto acadêmico de lógica fuzzy para a disciplina de Inteligência Artificial e Computacional.

## Tema
Priorização de tickets de suporte técnico acadêmico com sistema fuzzy Mamdani.

## Integrantes
- Gabriel Albuquerque
- Davi Maciel
- Alberto Acosta

## Modalidade
Opção B: aplicação ou produto baseado em controle fuzzy.

## Artefatos
- `src/fuzzy_system.py`: implementação do sistema fuzzy.
- `src/build_artifacts.py`: gera os PDFs do relatório e da apresentação.
- `docs/manual_execucao.md`: instruções de execução.
- `docs/declaracao_ia.md`: declaração de uso de IA.
- `docs/roteiro_gamma.md`: roteiro para gerar slides no Gamma.

## Execução
```bash
python src/build_artifacts.py
```

O comando gera os arquivos em `artifacts/`:
- `relatorio_fuzzy.pdf`
- `apresentacao_fuzzy.pdf`

## Dependências
- Python 3.13+
- `numpy`
- `matplotlib`

## Observação
O projeto foi mantido simples por decisão de escopo: um protótipo funcional, reprodutível e bem documentado.
